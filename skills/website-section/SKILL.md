# Website Section

Build one section well, ready to paste into an existing page.

## Ask first (only if missing)
- Which section
- The content (or let me write it)
- Existing site colours and fonts, or a link/screenshot
- Plain HTML/CSS, Tailwind, or React/Next.js component

## Section patterns
- **Hero**: headline, sub-line, CTA, visual. Split or centred layout.
- **Services**: icon + title + 1-2 lines per card, grid of 3 or 4.
- **Pricing**: 3 plans, middle one highlighted, feature list, CTA each.
- **Testimonials**: cards or slider, name + role + quote.
- **FAQ**: accordion that works without libraries.
- **Contact**: form + map/address + WhatsApp + phone.
- **Footer**: links, contact, social icons, copyright.

## Output
- The code in one block (or file)
- Where to paste it and any CSS variables to change

## Rules
- Match the existing style if given; don't redesign the whole site.
- Responsive: stacks cleanly on mobile.
- Use semantic tags (section, h2, button, form labels).
