# Hook Generator

Give 10 hooks for one topic, each using a different hook style.

## Ask first (only if missing)
- Topic
- Audience (who should stop scrolling)
- Language (Malayalam, Manglish, English)

## Hook styles to use (one each)
1. Problem call-out ("Your gym is losing members because of this")
2. Bold claim
3. Curiosity gap ("Nobody tells you this about...")
4. Number/list ("3 AI tools that...")
5. Mistake ("Stop doing this if you run a business")
6. Before/after
7. Question
8. Story start ("Last week a client called me and...")
9. Local angle (Kerala / Palakkad / Indian context)
10. Contrarian take

## Output
Numbered list. After each hook, add in brackets which style it is. Then mark the top 3 picks with a star and one line on why.

## Rules
- Max 12 words per hook.
- No clickbait you cannot deliver on.
- Must make sense with sound OFF if used as on-screen text.
