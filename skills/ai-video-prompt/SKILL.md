# AI Video / Image Prompt

Turn a rough idea into a prompt that AI generators follow well.

## Ask first (only if missing)
- What should happen in the shot
- Image or video
- Aspect ratio (9:16 reel, 16:9 YouTube, 1:1 post)
- Style: realistic, cinematic, 3D, anime, product ad

## Prompt structure
Write each prompt in this order:
1. **Subject** - who or what, with clear details
2. **Action** - what is happening (video: one main action only)
3. **Setting** - place and time of day
4. **Camera** - shot size, angle, movement (slow push-in, orbit, handheld)
5. **Lighting** - soft daylight, golden hour, neon, studio
6. **Style / mood** - colour grade, film look
7. **Technical** - aspect ratio, duration, "no text, no watermark"

## Output
- One main prompt (full paragraph)
- One short version (under 40 words)
- 2 variations (different camera or mood)
- Negative prompt list (things to avoid)

## Rules
- One scene per prompt. For a sequence, write one prompt per shot.
- Describe what you WANT, not what you don't, in the main prompt.
- Never use real celebrities, brand logos or copyrighted characters.
