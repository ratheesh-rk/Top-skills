# Thumbnail Brief

## Ask first (only if missing)
- Video title or topic
- Platform (YouTube 16:9 or Reels cover 9:16)
- Brand colours if any
- Face in the thumbnail or not

## Output
Give 3 options. For each:
- **Text on image** - max 4 words, big and bold
- **Layout** - where the face, object and text sit (left/right/centre)
- **Expression / pose** - if a face is used
- **Main visual** - the one object or idea that tells the story
- **Colours** - background, text, accent (high contrast)
- **Why it works** - one line

## Rules
- Text must be readable on a phone at small size.
- Thumbnail text should add to the title, not repeat it.
- One focal point only. No clutter.
