# Landing Page

Build a full one-page site in one HTML file that opens directly in a browser.

## Ask first (only if missing)
- Business name and what it sells
- Main goal: calls, WhatsApp, form leads, or sales
- Brand colours (or let me pick)
- Contact details (phone, WhatsApp, location)

## Sections (default order)
1. Navbar with logo text and CTA button
2. Hero: headline, sub-line, main CTA, image or visual
3. Services / features (3-6 cards)
4. Why us / benefits
5. Testimonials (placeholder text clearly marked)
6. FAQ (4-6 questions)
7. Contact / CTA section with WhatsApp button
8. Footer

## Tech
- One HTML file. Tailwind via CDN or inline CSS.
- Mobile-first. Test mentally at 375px width.
- Google Fonts allowed.
- WhatsApp link format: `https://wa.me/91XXXXXXXXXX`
- Placeholder images: solid colour blocks or gradients, not random stock links.

## Rules
- Headline says what they get, not "Welcome to...".
- One main CTA repeated, not five different ones.
- No fake reviews presented as real. Mark placeholders clearly.
- Good contrast, readable font sizes (body min 16px).
