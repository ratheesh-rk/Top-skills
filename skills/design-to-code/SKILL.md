# Design to Code

Recreate a layout from a screenshot or reference, adapted to the user's brand.

## Ask first (only if missing)
- The screenshot or reference link
- Whose brand: name, colours, fonts, real content
- Output: HTML/CSS, Tailwind, or React component

## Steps
1. Break the design into sections and a grid (columns, spacing, alignment).
2. Note the system: font sizes, spacing scale, radius, shadows.
3. Build structure first, then style, then responsive.
4. Swap in the user's content, colours and logo text.

## Output
- Working code
- A short list of design tokens used (colours, fonts, spacing)

## Rules
- Use it as layout inspiration only. Do not copy another company's logo, text, images or brand.
- Use the user's own content or clear placeholders.
- Make it responsive even if the reference was desktop only.
- Clean class names; no absolute positioning hacks for layout.
