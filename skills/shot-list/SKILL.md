# Shot List

Turn an idea or script into a list the shooter can follow on set.

## Ask first (only if missing)
- The script or idea
- Location (office, shop, farm, outdoor, studio)
- Gear: phone only, or camera + gimbal
- Who appears on camera

## Steps
1. Split the script into scenes.
2. For each scene list the A-roll shot and 1-3 B-roll shots.
3. Note angle, framing and movement for each.
4. Group shots by location so the shoot is fast.

## Output format
| # | Scene | Shot type | Angle / framing | Movement | Notes / props |
|---|-------|-----------|-----------------|----------|---------------|

Then:
- **Shoot order** (grouped by location)
- **Props and checklist**
- **Lighting tip** for that location

## Rules
- Default to vertical 9:16 unless told otherwise.
- Keep it doable on a phone.
- Every B-roll shot must match a line in the script.
