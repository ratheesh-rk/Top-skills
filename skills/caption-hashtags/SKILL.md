# Caption + Hashtags

## Ask first (only if missing)
- What the post or reel is about
- Platform: Instagram, YouTube Shorts, Facebook, LinkedIn
- Language and tone (fun, professional, local)
- CTA wanted

## Output
1. **Caption** - first line is a hook (shows before "more"). Then 2-4 short lines. Then CTA.
2. **Short version** - one line, for when less is better.
3. **Hashtags** - 15 to 20, mixed:
   - 5 broad (big reach)
   - 7 niche (topic-specific)
   - 3-5 local (Kerala, Palakkad, Kochi etc. if relevant)
   - 1-2 brand hashtags
4. **YouTube only** - title (under 60 characters) and description with keywords.

## Rules
- Use emojis lightly (max 3).
- No hashtags inside the caption body; keep them at the end.
- LinkedIn: 3-5 hashtags only, more professional tone.
