# Everyday Skills (20)

Simple Claude skills for video, web design, development and daily client work.

## Folders
- skills/        - one folder per skill, each with a SKILL.md
- upload-ready/  - each skill zipped on its own, ready to upload

## How to add a skill to Claude
Settings -> Capabilities (Skills) -> Upload skill -> pick a zip from upload-ready/.
Edit any SKILL.md to change the wording, then zip that folder again.
